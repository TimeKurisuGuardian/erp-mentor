# ERP Mentor Sandbox — Учебный портал (Аналитик 1С / ERP)

Интерактивный веб-тренажер для знакомства с основами сопровождения и анализа 1С/ERP без необходимости установки тяжелых локальных баз на старте.

## Что внутри

* **Теория короткими карточками** — разбор архитектуры 1С (Справочники, Документы, Регистры, Проводки, НДС) простым языком.
* **Интерактивный эмулятор документа 1С** — модель документа «Реализация товаров и услуг» с проверкой остатков, ошибками проведения, сменой склада и формированием проводок Дт/Кт.
* **Симулятор ServiceDesk / Jira** — практические тикеты 2-й линии поддержки с эталонными разборами и отправкой решения куратору.
* **Словарь терминов** — перевод IT-жаргона и терминов 1С на понятный язык.
* **Шаблоны практических заданий** — заготовки для быстрой сдачи первых домашних заданий.
